SmartAgro AI is a full-stack IoT-based precision agriculture and smart irrigation platform designed to help
farmers monitor crop conditions, automate irrigation, and optimize water usage using real-time telemetry
and AI-driven insights.

 Features: 
Real-time IoT sensor monitoring
Automated smart irrigation
AI-powered crop recommendations
Flutter mobile dashboard
Multi-farm and multi-zone management
Interactive analytics and data visualization
MQTT-based ESP32 integration
FastAPI backend with asynchronous processing

 Tech Stack-
 
Frontend:
Flutter,
Dart,
fl_chart

Backend:
Python,
FastAPI,
Uvicorn

IoT:
ESP32,
MQTT,
DHT 11/22,
Soil Moisture & Environmental Sensors

 Key Functionalities:
Live telemetry dashboard,
Remote pump control,
Historical analytics,
AI assistant integration,
Smart irrigation recommendations
